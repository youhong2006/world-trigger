# BORDER 總部日常生活與設施研究

> 資料分級：A = 原作或官方問答有支持（本文件部分透過非官方轉錄，待核對官方原文）；B = 根據原作設施推論；C = 為遊戲設計的新增內容。樓層位置均為 C，勿視為官方樓層表。

## 具作品或 BBF 問答支持的設施
1. **大型食堂（A，BBF Q207 二手轉錄）**：價格便宜，特色菜包含 A 級套餐、A 級和式套餐、變化炒飯。建模：點餐窗口、菜單燈箱、取餐口、餐桌、回收台、廚房後場。
2. **住宿／宿舍區（A，BBF Q199 二手轉錄）**：總部內有隊員及職員可住宿的區域。建模：寢室、床、書桌、衣櫃、走廊；浴室、洗衣間、共用休息室屬 C。
3. **自動販賣機與物資補給（A，BBF Q206 二手轉錄）**：販賣機飲品補充與地下進貨隧道、上下水／電／瓦斯等管線。建模：飲料販賣機、物流收貨口、搬運推車、貨梯、儲藏室；具體位置屬 C。
4. **小隊作戰室（A，作品畫面／資料整理）**：B 級以上正式小隊有專屬作戰室，包含討論桌、螢幕、操作員區、Bail Out 接收墊；A 級作戰室較大且可有簡易廚房。隊伍自訂裝潢可能含冰箱、遊戲機、暖桌、書架、電視。注意：不同隊伍配置不同，不應所有房間完全相同。
5. **單人 Rank 戰訓練室（A）**：虛擬模擬室與共用資訊看板。
6. **大型狙擊訓練場（A）**：適合建立獨立大型室內射擊場，配置靶位、觀察台、分數螢幕與安全隔離。
7. **立體投影會議室（A）**：中央全息投影與多側座席，用於顯示近界資訊。
8. **操作員工作區／指揮室／技術實驗室（A：功能存在）**：操作員監控、通訊、研發、設備維修；具體樓層和相對位置未知。
9. **地下遠征艇及 Mother Trigger 相關設施（A：作品資料支持）**：應採管制區域，詳細構造不應臆測為官方事實。
10. **遠征選拔封閉環境測試設施（A：漫畫情節）**：寢室、廚房、儲藏室、浴廁、工作桌、個人終端、膠囊床等；屬特定測試設施，不代表所有宿舍都如此。

## 推薦新增的日常生活設備（C）
- 公共休息廳：沙發、茶几、充電插座、飲水機、置物櫃、電視、遊戲角落。
- 餐廳細節：電子菜單、點餐機、餐盤回收、洗手台、微波爐、冰箱、餐具架。
- 宿舍生活：衛浴、淋浴、更衣間、洗衣／烘衣機、洗衣籃、鞋櫃、鏡子、夜間照明。
- 運動恢復：健身房、伸展區、簡易醫務室、急救設備、健康監測站。
- 教育與辦公：自習室、圖書資料室、簡報室、辦公桌、影印機、置物櫃。
- 設施維護：機房、空調、消防與避難指示、緊急照明、配電間、網路機櫃、清潔用品間、垃圾分類區。
- 物流安全：貨梯、出入門禁、訪客接待、監視設備、倉儲架、工具推車、備品倉庫。
- 總部氛圍：走廊導引燈、電子樓層圖、訓練公告板、出勤時刻表、隊員留言板、時鐘。

## 小隊房間設計差異
- 通用核心：隊伍門牌、電動雙扇滑動門、會議桌、隊員座位、戰術螢幕、操作員席、Bail Out 接收區。
- 可選模組：冰箱、暖桌、遊戲主機、書架、咖啡機、簡易廚房、休息沙發、展示櫃。
- 不應預設 C 級非正式小隊擁有專屬作戰室。
- 以資料驅動 squadId / rank / furnishings / doorAccess / operatorStation 配置，便於增修。

## 遊戲互動優先順序
**第一階段**：餐廳、販賣機、公共休息區、至少一間可探索小隊作戰室，搭配自動雙開門與導航。
**第二階段**：宿舍、衛浴、操作員工作區、狙擊訓練場、立體投影室。
**第三階段**：醫務、研發、物流、地下設施、生活 NPC 與晝夜活動。
所有設備先以低多邊形模組化白模驗證比例、碰撞和效能；互動可逐步增加，不要一次重構整個遊戲。

## 追加：七項可探索的日常與安全設施（C：遊戲原創設計）

下列設施**不是原作已確認的總部平面配置**，而是為了增加基地的真實性、可探索性與可玩性而規劃。實際樓層依空間與效能決定，不要宣稱是官方位置。

| 設施 | 建議內部配備 | 玩家互動 | 設計與安全重點 |
|---|---|---|---|
| 健身房 | 跑步機、腳踏車、重量訓練架、啞鈴、瑜伽墊、飲水機、置物櫃 | 使用器材動畫、體能訓練、休息 | 器材碰撞與安全通道，設備可重用模組 |
| 醫務室 | 診療床、醫藥櫃、急救箱、洗手台、監測螢幕、輪椅 | 與醫護 NPC 對話、休息／治療互動 | 不把遊戲治療機制說成真實醫療建議 |
| 自習室 | 個人書桌、閱讀燈、電腦、書架、白板、充電插座 | 閱讀資料、查詢任務紀錄、訓練教學 | 安靜區與照明分區，與休息區區隔 |
| 裝備維修室 | Trigger 工作台、工具櫃、零件架、測試台、檢修終端 | 檢視裝備、模擬維修／配裝介面 | 危險設備採權限與互動限制 |
| 倉庫 | 貨架、備品箱、條碼標籤、推車、庫存終端 | 查看物資清單、任務領取／歸還 | 保留搬運寬度，避免堆放阻擋出口 |
| 貨梯 | 大型雙扇滑動門、呼叫面板、樓層顯示、貨物平台 | 呼叫貨梯、選層、運送補給 | 與客梯分離；移動與門狀態同步；不讓玩家卡進井道 |
| 消防與避難 | 灑水頭、偵煙器、警報器、滅火器、緊急照明、逃生圖、樓梯間防火門 | 警報演練、辨識出口、緊急導引 | 逃生樓梯獨立連通；**防火門可依用途採鉸鏈門或其他合適門型，不強制使用自動滑動門** |

### 空間分區建議（C）
- 健身房、醫務室與自習室：鄰近公共生活區，方便隊員日常使用。
- 裝備維修室：鄰近技術研發區、訓練設施與後勤貨梯。
- 倉庫與貨梯：與地下補給通道、收貨區及技術區連接；不穿越公共餐廳或主要訓練大廳。
- 消防設備：各樓層分散配置，明確標示兩個方向的逃生導引（實際出口數與消防法規應依正式建築設計核對）。

### Codex 實作規範
1. 先建立 `facilityRegistry`，每項設施包含 `id`、`type`、`floorId`、`bounds`、`entrances`、`interactables`、`accessLevel`。
2. 優先完成七項設施的**可進入白模、門牌、照明、碰撞與室內動線**，再補充家具、動畫與 NPC。
3. 貨梯沿用電梯狀態機但使用獨立配置，並加入防止玩家掉入井道的碰撞保護。
4. 消防警報與避難導引可先做視覺與互動演示，不宣稱符合實際消防法規；避難路線不可被鎖門或可移動家具阻擋。
5. 所有新增場景需保留現有 Three.js 世界單位、玩家控制、戰鬥邏輯與 GitHub Pages 相容性。
6. 驗收：七區可由公共走廊抵達、門正常開關、樓層可達、碰撞正常、無明顯穿模；執行 `npm test` 和 `npm run build`。
