# BORDER 基地探索擴充版 — 2026-10-23

本版依使用者最新圖片與實作命令，將基地由南側局部設施擴充為四側連通的可探索建築。主屋頂維持 **350 m**，占地維持 **1,248 × 800 m**；四側可用建築區加深至 **160 m**，縮小中央中庭。外圍住宅室內不在本次範圍。

已重新讀取本資料夾的結構文件與 [9 張動畫參考圖](references.md)。設施外觀依動畫畫面（A）；部分空間連接採畫面推論（B）；下列樓層、尺寸、房間位置與動線均為遊戲設計（C）。尚未取得或核實 BBF 的完整官方平面圖，不將本版樓層表當作原作設定。

## 入口與建築比例

- 正面設置寬 14 m、高 18 m 的深色內凹雙扇大門，配合角形門框及旁側人員門。
- 城市前庭與入口同高，步行即可進入；**移除舊版抬高石質基座及入口斜坡**。這是使用者後續指定，取代 `exterior-massing-spec.md` 先前提出的外擴基座要求。
- 四側建築區由 67.2 m 加深至 160 m，採中空房間、走廊與樓板，不使用實心大碰撞盒填滿。
- 一般層高由 4 m 改為 **6 m**，一般隔間高約 **5.7 m**；門、桌椅與設備維持約 1.75 m 人物可用的尺度。
- 外牆仍輕微向內收，樓板、屋頂、門洞與斜牆碰撞按同一高度截面對齊。角塔及天線可高於主屋頂。

首頁點「探索 BORDER 基地」，由平地正面入口開始。穿過門廳可到四側環形主走廊；主走廊外另有平行次走廊與橫向通道，通往更細分的房室。服務核心提供電梯與連續實體樓梯，從地下連到 RF。

## 排名大廳與射擊場

**2F／3F 排名大廳**依參考畫面保留中央大型紅黑編號看板、挑空、上下走道、欄杆、左右樓梯及編號訓練入口。大廳位於正面翼的一部分，其他房室與四側動線仍可使用；服務樓梯另連通地下與屋頂。

**紅色／粉紅長帶是實際射擊訓練場。** 本版將其放在 7F 正面翼，樓面 36 m、頂部 60 m，長約 970 m、靶場區深約 144 m。場內有射擊隔間、控制終端、標線與亮青色靶心；玩家使用現有配裝發射的子彈可實際命中靶標。靶位終端顯示命中、發射數、用時及擊破進度，並可重置靶標；最佳成績保存在本機 `mikado-hq-live-range-best`。

獨立網格模擬訓練仍保留，與實體射擊場分開。訓練終端啟動六靶虛擬場，沿用目前觸發器與近戰／蚱蜢操作；F 返回原終端、R 重試。模擬城市不視為總部內實際建造的城市，最佳成績另存於 `mikado-hq-training-best`。上述兩種基地訓練紀錄尚未納入原戰鬥 JSON 備份。

## 導覽與互動

- **F**：使用門、終端、座椅；再按 F 安全站起。作用距離 2.5 m，需面向物品，牆壁及關閉的門會遮擋。
- 接待導覽提供樓層平面圖、四翼選擇、房間搜尋與目的地標記；畫面提示沿走廊及電梯前往，避免只顯示直穿房間的目的地方向。
- 電梯依功能區分組列出樓層，可搜尋與選擇目的地；實際轎廂載人移動，對齊樓層後開門，門口有人時阻止啟動。
- 滑動門兩片門板及其碰撞同步移動，保留自動感應、手動互動、延遲關門及防夾。
- 椅子、長椅、沙發及床邊可休息；坐下時停止移動、跳躍和攻擊，站起時尋找合法空位。床位目前使用床邊坐姿，尚無平躺動畫。
- 裝備櫃、維修終端可接上原配裝；任務／戰術終端可接上原單人任務；醫務設備查看部位狀態，不改變「少量恢復不修復斷肢」的規則。
- 食堂／販賣機可領取餐飲並計數，限本次會話；教學、避難導覽、城市觀測及可開關的立體投影可用。
- **Esc** 先關閉目前設備介面，F2 開設定。**Z 為切換射擊側，Alt 為方向閃避**；F 已保留基地互動，舊預設按鍵會遷移。

## 碰撞與分區載入

外牆、隔間、樓板、天花板、樓梯踏面、護欄、門、電梯及主要家具均使用實際碰撞；發光貼條及文字不額外增加阻擋。主體樓板、服務核心和連續樓梯保留，房室細節按玩家附近分區載入，避免一次繪製全基地。

附近房室以共用材質及 InstancedMesh 合併；離開的分區會釋放幾何、互動物件和碰撞索引。快取上限為 16 個區段。碰撞索引同時按平面與高度分層，動態轎廂另參與支撐查詢。全高度配置不代表每一層的家具同時顯示。

## 驗證方式與範圍

執行 `npm test` 和 `npm run build`。基地測試涵蓋四翼與高低樓層、房間與主走廊邊界、街道平地入口、實體樓梯、電梯載人及防夾、不同朝向的滑動門、分區碰撞卸載、射擊場挑空及命中／重置，以及地形挖空。

瀏覽器操作另需核對 F 使用設備／座椅、導覽篩選與目的地、電梯選層、實體靶場射擊、虛擬訓練返回和原城市戰鬥。軟體 WebGL 的操作驗證不能作為一般硬體 FPS 保證。

### 本版驗證結果

- `npm test`：146 項通過，0 失敗。包括 181 段實體樓梯、交錯樓梯出口、四翼七條平行走廊與橫向通路、2F／3F 連橋、電梯載人及 129 m 實體小行星彈命中。
- `npm run build`：通過。建置仍有單一 JavaScript 套件超過 500 kB 的大小提示。
- Chromium／軟體 WebGL，載入完整 12,408 棟城市：入口與室內顯示、7F 靶場啟動、導覽搜尋及平面圖、選層搭乘至 58F、F 坐下／站起、虛擬訓練進出通過，無頁面執行錯誤。導覽視窗無橫向溢位。
- 畫面核對後已修正戶外地坪覆蓋室內、靶場天花板隨一般樓層被隱藏，側向座椅靠背／扶手旋轉，以及靶位控制台阻擋槍口問題。

- 完整城市原戰鬥回歸：AI 出生點合法、獵犬擊破移動目標、近戰命中、第一人稱武器、左手刀動畫及緊急脫離通過，無頁面或著色器錯誤。
