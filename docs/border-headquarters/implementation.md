# BORDER 獨立基地世界（V1.0.1）— 2026-10-24

依使用者最新命令，三門市中的 BORDER 只保留實心外觀基地與正門傳送入口；原本位於城市建築內的設施、房室、樓板、樓梯、電梯、互動物件及其碰撞，移至獨立的 **BORDER 基地世界**。原版 [V1.0.0](https://github.com/youhong2006/world-trigger/tree/V1.0.0) 備份保留。

獨立基地沿用上一版已完成的四側走廊與重要設施：主屋頂 **350 m**、占地 **1,248 × 800 m**、四側可用建築區深 **160 m**、一般層高 **6 m**，地下維持一座大型遠征艇機庫。外圍住宅室內不在本次範圍。

設施外觀依 [9 張動畫參考圖](references.md)（A）；部分空間連接採畫面推論（B）；下列樓層、尺寸、房間位置、動線及世界傳送機制均為遊戲設計（C）。尚未取得或核實 BBF 的完整官方平面圖，不將本版樓層表當作原作設定。

## 城市正門與傳送方式

- 城市中的基地採與外觀一致的實心碰撞，封閉內部及屋面；不再放置原本可探索的室內設施或保留交通核心的穿透開口。
- 正門保留平地前庭，新增亮青色傳送門與標示。首頁「探索 BORDER 基地」先到城市正門；走入入口或在門口按 F，傳送到基地世界的入口大廳。
- 基地世界的正面入口設返回傳送門。離開後回到城市正門外的安全位置，避免剛傳送完立刻再次觸發入口。
- 基地內仍沿四側環形主走廊、次走廊及垂直交通核心前往設施；「基地平面導覽」的目的地標記提供步行方向，不會直接傳送到各房間。
- SIM-01 是基地世界內另外啟動的模擬訓練場。按 F 先回到啟動訓練的基地終端，再由基地入口返回三門市。

## 世界與碰撞分離

| 世界 | 場景內容 | 碰撞／地面 |
| --- | --- | --- |
| 三門市 | 城市、實心 BORDER 外觀及正門傳送入口 | 城市專用索引；沒有基地房室或設備碰撞 |
| BORDER 基地世界 | 原基地內部、重要設施、走廊、四處交通核心、實體射擊場及返回入口 | 獨立基地索引與地下／樓板支撐 |
| SIM-01 | 青色網格六靶訓練空間 | 獨立訓練索引；返回原基地終端 |

切換時使用目前世界的渲染場景、碰撞及地面查詢，角色和共用操作效果隨角色切換；城市與基地世界可以使用相同座標，但不會彼此阻擋。城市中的實心基地不再當作室內探索空間，亦不會在城市內隱藏地留著一套房間碰撞。

以下的樓層、房室、設施及垂直交通配置，皆指 **BORDER 基地世界**。正面大門、深藍金屬壁板、青色導引燈帶與門牌沿用上一版風格；機庫使用橄欖灰與淡黃配色。

## 排名大廳與射擊場

**2F／3F 排名大廳**依參考畫面保留中央大型紅黑編號看板、挑空、上下走道、欄杆、左右樓梯及編號訓練入口。大廳位於正面翼的一部分，其他房室與四側動線仍可使用；服務樓梯另連通地下與屋頂。

**紅色／粉紅長帶是實際射擊訓練場。** 本版將其放在 7F 正面翼，樓面 36 m、頂部 60 m，長約 970 m、靶場區深約 144 m。場內有射擊隔間、控制終端、標線與亮青色靶心；玩家使用現有配裝發射的子彈可實際命中靶標。靶位終端顯示命中、發射數、用時及擊破進度，並可重置靶標；最佳成績保存在本機 `mikado-hq-live-range-best`。

**SIM-01 獨立模擬訓練空間**依 `訓練空間.jpg` 與 `訓練空間2.jpg` 改為約 180 × 180 m 的封閉式場地：高牆、窗格、灰白建築、藍色寬樓梯、6 m 高觀察平台及建築高低差。亮青色網格直接繪製在地板、牆面、樓梯與建築材質上，減少重疊平面閃爍。這是獨立模擬場景，與實體射擊場分開。

訓練終端啟動六靶虛擬場，沿用目前觸發器與近戰／蚱蜢操作；F 返回原終端、R 重試。模擬城市不視為總部內實際建造的城市，最佳成績另存於 `mikado-hq-training-best`。上述兩種基地訓練紀錄尚未納入原戰鬥 JSON 備份。

## 導覽與互動

- **F**：使用門、終端、座椅；再按 F 安全站起。作用距離 2.5 m，需面向物品，牆壁及關閉的門會遮擋。
- 「基地平面導覽」優先列出重要設施，卡片顯示中文名稱、代號、樓層與所屬翼；下方仍可篩選樓層、四翼與房間名稱。平面圖顯示特殊設施範圍及 T01–T04 核心，選取後提供步行目的地提示。
- 設施出入口、樓層與交通核心設有中文方向牌；目前所在設施與樓層也顯示於介面。
- 「畫面問題紀錄」可記下目前座標、樓層及描述，並在導覽圖和附近提示中標示。新紀錄為「待核對」，可標記位置、標為已修復、重新開啟、刪除或匯出 JSON。紀錄保存在目前瀏覽器，**不會自動送出到 GitHub**。詳見 [畫面問題紀錄](visual-issues.md)。
- 電梯依功能區分組列出樓層，可搜尋與選擇目的地；實際轎廂載人移動，對齊樓層後開門，門口有人時阻止啟動。
- 滑動門兩片門板及其碰撞同步移動，保留自動感應、手動互動、延遲關門及防夾。
- 椅子、長椅、沙發及床邊可休息；坐下時停止移動、跳躍和攻擊，站起時尋找合法空位。床位目前使用床邊坐姿，尚無平躺動畫。
- 裝備櫃、維修終端可接上原配裝；任務／戰術終端可接上原單人任務；醫務設備查看部位狀態，不改變「少量恢復不修復斷肢」的規則。
- 食堂／販賣機可領取餐飲並計數，限本次會話；教學、避難導覽、城市觀測及可開關的立體投影可用。
- **Esc** 先關閉目前設備介面，F2 開設定。**Z 為切換射擊側，Alt 為方向閃避**；F 已保留基地互動，舊預設按鍵會遷移。

## 碰撞與分區載入

外牆、隔間、樓板、天花板、樓梯踏面、護欄、門、電梯及主要家具均使用實際碰撞；發光貼條及文字不額外增加阻擋。主體樓板、四處服務核心和連續樓梯保留，房室細節按玩家附近分區載入。跨層特殊設施另保留挑空、周邊環廊與必要通行橋，避免一般樓板橫穿整座大廳。

附近房室以共用材質及 InstancedMesh 合併；離開的分區會釋放幾何、互動物件和碰撞索引。快取上限為 16 個區段。碰撞索引同時按平面與高度分層，動態轎廂另參與支撐查詢。全高度配置不代表每一層的家具同時顯示。

## 驗證方式與範圍

執行 `npm test` 和 `npm run build`。本版另需核對城市實心外殼、傳送門接近／互動／重複觸發、世界專用碰撞、場景歸位、訓練返回，以及離開基地後的城市戰鬥。既有基地測試涵蓋四翼與高低樓層、房間與主走廊邊界、街道平地入口、實體樓梯、電梯載人及防夾、不同朝向的滑動門、分區碰撞卸載、射擊場挑空及命中／重置，以及地形挖空。

瀏覽器操作另需核對 F 使用設備／座椅、導覽篩選與目的地、電梯選層、實體靶場射擊、虛擬訓練返回和原城市戰鬥。軟體 WebGL 的操作驗證不能作為一般硬體 FPS 保證。
