# BORDER 基地探索初版 — 2026-10-23

本次依使用者實作命令，將既有基地改為可從城市步行進入的探索初版；外圍住宅室內不在本次範圍。使用者後續指定主體屋頂高度為 **350 m**，角塔及天線可高於主屋頂，原有 1,248 × 800 m 基地占地保留。外牆每側內收約底面尺寸 4%，使用實際斜面幾何與相同凸體碰撞。

本版依 `docs/border-headquarters` 的 8 份原有規格文件、9 張 JPG，以及使用者貼上的分享聊天內容製作。設施種類與部分視覺參考動畫（A）；對稱大廳及上下走道關係含畫面推論（B）；全部樓層、尺寸、房間位置、服務核心與可玩設備配置為遊戲設計（C）。沒有取得或宣稱核實 BBF 完整官方平面圖。

## 入口與動線

首頁點「探索 BORDER 基地」，出生於南側入口坡道。WASD 沿坡道進入雙扇感應門，穿過門廳抵達中央走廊；左右房間可感應開門，F 可與門及設備互動。東端為電梯與連續維修樓梯。

本版開放南側主要設施翼，而非把整座巨型外殼填滿一般房間。一般樓層相距 4 m；上方服務空間由完整維修樓梯與快速電梯通往 350 m 屋頂。B1/B2 相對 1F 向下，位於基地抬高基座內，地板與城市地形碰撞已分開。

## 可用互動

- F：開門、使用終端、坐下／站起。作用距離 2.5 m，需面向物品，牆壁與其他門會遮擋；物品自身表面不會錯誤阻擋其互動。
- Z：切換射擊側，E 仍生成觸發器。舊預設 F 射擊側自動遷移，保留其他自訂按鍵，所有操作仍可改綁。
- 椅子、長椅、沙發及床邊休息採骨骼坐姿；坐下時停止移動、跳躍和攻擊，F 安全站起。床位目前為床邊休息姿勢，尚無平躺動畫。
- 接待導覽顯示樓層；門禁、電梯呼叫／選層、裝備櫃與維修終端、配裝及原有保存功能可用。
- 訓練終端進入獨立網格模擬場，六個實際可擊破的靶標、近戰／射擊及蚱蜢練習，F 返回原終端、R 重試。最佳成績保存在本機獨立鍵值 `mikado-hq-training-best`，尚未納入原戰鬥 JSON 備份。
- 任務／戰術終端開啟原有單人任務；醫務終端讀取戰鬥體部位狀態，不修復斷肢；倉庫顯示目前配裝。
- 食堂與販賣機可領取餐點／飲品並計數，本次會話有效；教學、避難路線、城市觀測、可開關的立體投影可用。
- Esc 先關閉設備，恢復場景操作；F2 及原設定、配裝、射擊選單保留。

## 碰撞與效能

牆、門、地板、天花板、每個樓梯踏面、護欄及主要家具均有碰撞，發光貼條／文字等表面裝飾不另擴張碰撞。滑動門兩片實際移動並各自更新碰撞；電梯載人、轎廂關閉與到站門狀態共用同一位置資料。原高速細分碰撞持續使用。

室內家具及踏面依樓層／材質合併為 InstancedMesh，僅顯示附近樓層，碰撞一直保留。碰撞索引增加 6 m 高度分層，避免每次行走都掃描全部垂直樓梯；動態電梯支撐面始終參與查詢。

## 驗證

`npm test` **125 項全部通過**，`npm run build` 成功。新增測試涵蓋：350 m 尺寸、斜牆人物／鏡頭、從街道經坡道及門進入房間、B2 至 RF 全部實體樓梯、電梯載人與到站門、防夾、視線遮擋、舊按鍵遷移、訓練大廳挑空與內部樓梯。

Chromium / Playwright 操作檢查涵蓋 F 坐下／站起、禁止坐下時移動與射擊、導覽與 Esc、啟動訓練、實際子彈命中與返回、電梯選層及頂樓；另使用完整 12,408 棟城市檢查入口與載人碰撞。瀏覽器驗證使用軟體 WebGL，不能據此宣稱一般硬體的 FPS 或所有 Windows 電腦效能。
