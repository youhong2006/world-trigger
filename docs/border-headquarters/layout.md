# BORDER 總部樓層、空間與動線規劃

## 確定的視覺線索（A）
- 訓練大廳：挑空空間、上下走道、欄杆、左右樓梯、編號門、中央大型狀態看板（第 19 集）。
- 大型螢幕：可展示地圖／名單，下方有編號顯示（第 20 集）。
- 訓練場景：藍色網格包覆地形、牆體、坡道與建築（第 17 集）。

## 空間關係（B）
- 訓練大廳可採中央挑空 + 兩側多層走道 + 樓梯連通的模型。
- 獨立訓練室入口由大廳的走道抵達，但房間後方實際構造未知。
- 第 17 集模型可能是訓練系統的可視化，而非實體總部剖面。
- 指揮區、隊伍活動區、研發區確切位置均未知。

## 可實作的概念性分區（C；不是官方樓層表）
- HQ_PUBLIC：入口／公共集合區。
- HQ_TRAINING_ATRIUM：多層挑空訓練大廳，中央看板與編號門。
- HQ_TRAINING_ROOMS：可擴充的獨立訓練室群。
- HQ_TEAM：隊伍作戰與活動區。
- HQ_COMMAND：指揮與監控區。
- HQ_ENGINEERING：研發與設備區。
- HQ_UNDERGROUND：地下機庫／通道預留。
- SIM_ARENA：**獨立虛擬場景**，不當作 HQ 的實體房間。

## 建議動線（C，參考動畫畫面）
入口 -> 大廳 -> 看板／集合區 -> 樓梯／上層走道 -> 指定訓練室 -> 載入模擬戰鬥 -> 返回訓練室／大廳。
隊伍活動區與指揮區另設權限控制與連通走道；維修區與機庫保留獨立後勤動線。以上順序是遊戲設計，不是官方平面圖。

## 暫定比例（C，僅為建模起點）
- 一般走道：寬 2.5–4 m
- 公共挑空大廳：高 8–15 m
- 一般樓層：高 3.5–4.5 m
- 訓練室：5×6 至 8×10 m
- 隊伍作戰室：6×8 至 10×12 m
- 主要樓梯：寬 2–3 m
- 大廳初始佔地：30×40 m 以上

請先對照專案既有的 1.75 m 人物、2.1 m 門與 3.3 m 住宅樓高設定調整尺度，避免改動全域世界單位。

## 實作順序
1. 檢查現有 BORDER 模型與玩家碰撞。
2. 建立不破壞既有城市的總部入口。
3. 建立大廳白模（牆／地板／樓梯／欄杆／門）。
4. 加入編號看板、地圖螢幕與互動入口。
5. 增加訓練室並銜接獨立的模擬戰鬥場景。
6. 補上導航、碰撞、鏡頭與效能測試。

## 小隊專屬房間（C：使用者指定的遊戲設計）
- 在總部規劃各小隊專屬作戰室，供隊員集合、討論戰術、檢視地圖、裝備與任務資訊。
- 使用可擴充的資料驅動配置：每間房有 teamId、teamName、roomId、accessLevel、doorId 與座標，不預先宣稱所有小隊官方房間位置。
- 建議配置中央戰術桌／顯示幕、隊員座位、置物櫃、隊徽與可更新的隊伍資訊；不同小隊可依設定微調風格。
- 房間由公共走道抵達，依權限或互動觸發開門；玩家不可穿牆，關門時需有碰撞。

## 電動雙開滑動門（C：專案美術與互動規格）
- BORDER 總部多數室內門採科技感電動**雙扇橫向滑動門**，兩片門板向左右分開，不是向外旋轉的鉸鏈門。
- 門框金屬灰／白，加入門牌、細緻燈條、狀態燈、門禁面板；保持與動畫科幻美術一致，勿將此設計冒充全部官方門型。
- 建議門寬 2.0–2.8 m、高 2.2–2.6 m（C，依人物與走廊比例調整）。
- 門狀態：CLOSED → OPENING → OPEN → CLOSING；玩家靠近或互動時觸發，離開後延遲關閉；關門遇到玩家／障礙物須停止或重新開啟。
- 動畫建議 0.6–1.0 秒、ease-in-out，左右門板各沿 X 軸滑動半個通道寬；門開啟時同步更新碰撞體。
- 重要區域可有門禁與鎖定狀態；安全出口須有合理的緊急通行設計。
