# 角色操作

從住宅街等地點選擇「開始漫遊」後，以鍵盤與滑鼠操作角色。畫面下方的按鈕可切換視角、蹲下與返回起點，狀態標籤顯示角色目前動作。

| 操作 | 按鍵／方式 |
| --- | --- |
| 前後左右移動 | WASD 或方向鍵 |
| 跑步 | 按住 Shift |
| 跳躍 | Space |
| 蹲下／站立 | C 切換 |
| 第一／第三人稱 | V 切換 |
| 環顧四周 | 移動滑鼠；未鎖定游標時按住畫面拖曳 |
| 調整跟隨鏡頭距離 | 第三人稱下滾動滑鼠滾輪 |
| 返回本次漫遊起點 | R |
| 釋放游標操作下方按鈕 | Tab；點擊場景重新鎖定 |
| 離開漫遊 | Esc |

第一人稱視線與角色站立、蹲下高度一致；第三人稱則能觀察角色與動作。切換視角會沿用原本位置及朝向，無須重新進入城市。

站立身高約 1.75 公尺、視高 1.63 公尺；蹲下身高為 1.05 公尺、視高 0.95 公尺。角色採 VRoid Studio 的正常成人比例動漫男性，灰紫短髮與深色制服。八組 CC0 移動動畫由 Quaternius 的標準動作庫重定向，蹲下時另做小幅軀幹姿勢調整，以符合低處通行的身高。

移動採加減速，斜向不會比直線更快。跳躍具有重力與落地過程，空中可有限度修正方向；按住跳躍鍵不會自動連跳。蹲下時降低身體高度與速度，頭頂空間不足時會維持蹲姿。

角色可沿緩坡移動並跨越低路緣，陡坡與建築等障礙仍會阻擋通行。第三人稱鏡頭會在牆面附近縮短跟隨距離。河流與世界邊界保留探索限制；目前以城市步行為主，未加入游泳或攀爬建築。

三座橋梁的入口由緩坡銜接，正常走路即可跨橋。鏡頭太貼近角色時會暫時隱藏角色，避免遮滿畫面；離開牆角後恢復顯示。

若遇到地形卡點，按 R 返回本次漫遊起點；選擇其他地點後再開始漫遊，會更新此起點。桌面鍵盤與滑鼠可使用完整角色操作，手機螢幕仍以場景預覽及介面操作為主。
