# 機動演習驗證與範圍

本文件記錄前一版設定／科技 UI、三離子共用基礎、高速移動及蚱蜢的驗證。後續小行星射擊、完整配裝與存檔的結果另見 [射擊演習驗證](shooting-validation.md)。AI、刀劍與部位損傷尚未提供。

## 自動檢查

執行 `npm test` 與 `npm run build`。本次 63 項 Node 測試與正式建置通過，測試涵蓋：

- 原有城市比例、街廓、橋梁、碰撞、角色模型、動作及鏡頭。
- 設定輸入限制、非法資料、按鍵衝突互換、本機儲存與草稿匯入。
- 三離子消耗、恢復等待、暫停、傷害／洩漏接口、耗盡及重整。
- 蚱蜢前後左右／斜向／無輸入方向、地面延遲觸發、空中立即觸發與持續接續。
- 從空中踩回地面跳板、一次性使用、到期移除、失敗不扣款及取消準備。
- 最大速度下的薄牆、薄天花板、快速下降落地與離開屋頂，30／120 Hz 一致性。
- 斜屋頂支撐、空中跨河，以及可調鏡頭視野、肩部與減少動態效果。

## 瀏覽器檢查

使用 Chromium 與 Playwright，分別檢查完整城市及輕量場景的操作生命週期：

- 完整城市載入 12,408 棟建築，角色、首頁、HUD、準備光球與彈射顯示正常。
- 地面準備／放置／踩踏，空中接續與無方向輸入垂直彈射。
- 平頂、切妻及寄棟屋頂實際落地與放置蚱蜢。
- 速度、靈敏度、視角、音量、畫質、陰影、HUD 與準星設定生效。
- 按鍵改綁／取消、設定及配裝／彈道草稿重載保存、JSON 匯入／匯出及錯誤檔案處理。
- 開選單後位置與資源凍結，準備中的技能取消，關閉後不殘留移動輸入。
- 游標鎖定（含延遲取得鎖定）、Tab 釋放及焦點切換、Esc 暫停、F2 設定與視窗失焦。
- 三離子耗盡後無法施放、顯示重整提示、返回起點後恢復資源與清除跳板。
- 390 像素寬度的五個終端頁面不產生水平溢出；桌面與手機均檢視畫面。

測試環境的 Chromium 使用軟體 WebGL；可驗證渲染、操作及錯誤，無法代替各裝置的硬體效能測量。低畫質、解析度倍率、細節距離與 FPS 顯示可協助實際使用時調整。沒有把軟體渲染測試宣稱為所有裝置都能穩定 60 FPS。

## 後續範圍

專屬逐格蚱蜢動畫、敵人／武器命中、斷肢、完整緊急脫離演出與閃避無敵判定仍屬後續。三離子數值、跳板壽命與速度是可繼續調整的演習參數。
