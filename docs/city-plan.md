# 三門市：第一版大範圍場景配置

依據使用者提供的兩張原作城市遠景圖，先建立空間關係與整體比例，再逐區加入後續參考細節。

## 從參考圖建立的配置

- BORDER 是城市中央的巨型地標，外圍有明顯清空的土色腹地。
- 密集的灰白低層住宅向四周擴展；靠近前景河岸的城區混入較高的公寓。
- 河流在城市前方橫向穿過，橋梁連接兩岸道路與南側住宅區。
- 深綠樹林、開放草地與農地穿插在住宅區外圍，而非只有整片建築。
- 綠色丘陵與多層遠山包圍城市，天空改為明亮的藍色。

## 目前使用的場景座標

X 為左右方向，負 Z 朝向遠景山群。主要聚落約 7 × 6 公里，步行邊界沿盆地外圍的不規則山勢延伸。

| 區域 | 位置 / 配置 |
| --- | --- |
| BORDER 本部 | 中心 (0, -150)；主體 1,248 × 800、高 864（相較上一版的長寬高各為 5 倍），另加塔樓與天線 |
| 本部腹地 | X ±770、Z -680 至 415；外側環形聯絡道 |
| 密集城區 | 基地四周向外延伸約數公里；聚落密度隨不規則盆地半徑與地形逐漸降低 |
| 河流 | 基地前方更外側，中央 Z = 1,250，西側較北、東側較南，沿兩端山谷延續 |
| 三座橋梁 | X -1,008、0、1,008，長 164，連接新河道兩岸 |
| 西側眺望點 | (-2,200, 120)，設於連續丘陵地形上，有沿坡步道 |
| 遠山 | 四周環繞盆地，以同一張連續高度場形成山麓與山脊，河流經山谷穿出 |

座標、建築數量、路網與未辨識的地點是便於後續調整的規劃值，並非已確認的原作精確地圖。後續圖片若顯示不同的方位或比例，應調整共用配置，而不是在局部另外堆疊不一致的場景。

## 配色基準

- 天空：亮藍 `#72b5e4`
- 河水：中藍 `#367fa4`
- 林地：深綠 `#2a633f` 至 `#56884b`
- 草地：綠色 `#75a35d`
- 民宅：灰白與米白，屋頂以灰藍、灰褐為主
- BORDER：灰藍偏紫外牆，土色腹地

## 開發與驗證

`src/city-layout.js` 供場景、河流通行、小地圖與步行地形共用；`src/city.js` 建立城市；`src/headquarters.js` 保留基地細節。建築和樹木使用實例化渲染，建築碰撞使用空間索引。

```sh
npm run build
node --test src/city-layout.test.js
```

瀏覽器需另外驗證城市總覽、拖曳與縮放、各地點傳送、跨橋步行及日夜切換。


## 基地五倍放大與中庭修正

依新增俯視參考圖，將封閉屋頂改為四面外牆圍住的露天中庭；可從空中看見分層內牆、地板格線、屋頂環狀走道，以及角塔的凹入頂部。中庭約 1,113.6 × 665.6。基地使用固定的「前版比例 3.2 × 5」設定，避免後續調整時重複累乘。

外圍腹地與環繞道路同步擴大，住宅與樹木避開新範圍；住宅街步行起點移到南岸 (-504, 720)，西側眺望點移到 (-985, 120)。小地圖與相機一併更新。新增圖片仍未確認建築的實際公尺數，以上為依使用者指定倍率放大的場景單位。


## 依紅、藍、綠標示重整城市外圍

- **紅色標示**：主要城市擴展為約 7 × 6 公里，由不對稱的盆地半徑控制聚落分布；不是矩形裁切，也不是在舊方形地板外再加一層方塊。
- **藍色標示**：河流從原本緊貼基地的 Z 約 554，移到中央 Z = 1,250，並形成由西北側向東南側延伸的彎曲河谷。兩岸都有住宅、道路與農地。
- **綠色標示**：山麓從城市外緣逐步升高，林地銜接住宅與山地；遠山環繞整個盆地。河道兩端保留自然山谷。

`src/landscape.js` 建立一整張半徑 18 公里的連續地形網格與漸層地表配色，替代先前的大型正方形底板及逐片山丘。地形、步行高度、道路、建築地基及小地圖共用 `terrainHeight`。聚落密度使用平滑衰減，住宅依坡度避讓，外緣混入農地與樹林；步行邊界跟隨山勢。基地倍率與中庭保持不變。

## 日式動畫街景與人物尺度

依街景參考圖，建築改為米白、灰藍、淡綠、灰粉色外牆，搭配灰藍、暗紅與深綠瓦屋頂。民宅以 2–3 層為主，公寓使用多層陽台及水平樓板線。切妻、寄棟和平屋頂混合分布。

- 每棟建築的長、寬相較前版均放大 35%；層高統一為 3.3 公尺，門高 2.1 公尺、門寬 1 公尺，窗戶按每一層及實際面寬重複，避免把整張窗戶材質拉成巨大的窗格。
- 步行視線高度 1.68 公尺，步行速度 2.2 m/s、衝刺 6.2 m/s，步行視角 62 度。住宅街傳送點移到路段中間，方便以人物高度觀察立面。
- 屋頂加入瓦片紋理、屋脊與白色簷口；近景加入門廊、雨槽、冷氣外機、陽台、平屋頂女兒牆及公寓服務核心。
- 放大後的地塊重新檢查道路、巷弄與鄰房碰撞，入口朝向相鄰街道。一般道路新增人行道，街廓內加入共用巷道。
- `src/building-metrics.js` 共用人物、門窗、樓層及地塊尺寸；`src/architecture.js` 依空間分批渲染建築，近距離才顯示細部零件。

基地、河流、盆地及山群的世界尺度不變。房屋大小依人物比例與建築樓層重新校正，並非直接把門窗一起等比例拉大。

```sh
node --test src/city-layout.test.js src/building-metrics.test.js
```


## 連續住宅街廓與再次放大 1.25 倍

本次房屋長、寬為上一版的 1.25 倍（累計初始基準 × 1.6875），門窗、樓高與人物視線維持公尺尺度。核心區不再使用固定候選點加隨機空地的方式，避免大房型遭地塊裁切後留下大片空洞。

- 保留 144 公尺的聯絡路網，每個街廓增加一條東西向 5 公尺巷道；沿路安排連續住宅列，兩列住宅後側相對。先決定房屋尺寸，再分配面寬，側邊本體間距約 2.4 公尺，屋簷仍有間隔。
- 支路寬 6 公尺、幹道由 18 縮至 12 公尺；基地的 16 公尺環道保留。窄巷設白色邊線，幹道保留中央虛線與人行邊帶。不同等級路面用微小高差避免交會處共面干擾，步行高度使用同一份道路設定。
- 宅前退縮 3.8 公尺，改為混凝土鋪面、低圍牆、入口缺口、信箱、窄植栽及停車格；部分停放長 3.4、寬 1.48 公尺的輕型車。低牆與車身納入步行碰撞。
- 公寓使用整個深度地塊，不再硬塞入雙排住宅的半深地塊；仍集中在靠近南側河岸的城區。
- 住宅核心區填滿可建地塊，山麓依不規則盆地密度逐漸減少。林地、河岸、基地腹地與坡度限制仍保留。
- 此固定種子的實際場景生成 12,408 棟建築（前版 7,350 棟），含 104 棟公寓、12,408 個門前車格及 4,127 台停車。數量由地形、河流與碰撞避讓共同決定。

`src/neighborhood.js` 負責實際尺寸分地塊；`src/neighborhood.test.js` 在 180 個種子街廓上檢查覆蓋率、沿街連續性、鄰屋間距、屋簷與陽台避讓、入口退縮及外緣淡出。住宅街起點移到南岸巷道內 (-1,070, 1,080)，方便直接比較人物高度下的街景密度。

```sh
node --test src/*.test.js
```
