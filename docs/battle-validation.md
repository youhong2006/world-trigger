# 單人戰鬥初版驗證

本版完成先前清單的 AI、近戰、防禦、部位損傷、緊急脫離、美特拉與任務流程。網站仍包含原有城市探索、射擊演習、自由配裝、彈道編輯及即時發射選單。

## 可重現檢查

```sh
npm ci
npm test
npm run build
npm run preview -- --port 4173
```

`npm test` 共 **113 項通過**，正式建置成功。涵蓋既有城市／骨架／高速碰撞／鏡頭／射擊／發射選單，以及下列新增案例：

- 六部位耐久、斷臂側別、斷腿速度／跳躍影響、持續洩漏、暫停傷害及重整；恢復不修復部位。
- 三段輕擊、蓄力重擊、空斬、硬直恢復、取消窗口、同一揮刀命中去重。
- 正面招架、較晚防禦消耗、背後突破、無無敵時間閃避與牆面碰撞；快速重開防禦不會無限刷新招架窗口。
- AI 感知、追擊、預兆、攻擊、失去視線搜尋、重新發現、局部繞行、裝甲與核心弱點。
- 實際毒蛇彈命中 AI 核心；獵犬與移動中的 AI 共用飛行及命中規則。
- 靜止在 280 m 高度仍會被 AI 發現並受到對空攻擊，避免合法高度範圍內的永久空中免疫。
- 美特拉範圍傷害衰減、掩體遮擋、同目標去重與固定射擊消耗。
- 三種任務的勝利、最佳紀錄、手動／離區脫離、重試清理；非法紀錄與任務選項防護。

## Chromium／Playwright 操作驗收

已使用系統 Chromium、WebGL 與 Playwright 操作鍵盤及滑鼠，收集頁面執行與著色器錯誤。檢查範圍如下。

### 完整城市

保留全部 **12,408 棟建築**與實際 BORDER 碰撞體：

- 討伐核心及四個護衛均生成在合法位置，未落入基地附樓或掩體。
- 以實際獵犬彈擊破移動中的敵人，並以實際刀劍命中敵人。
- 第一人稱有獨立持刀顯示；第三人稱及副側刀劍可使用原生骨架動作。
- 主動緊急脫離能走到結果頁。
- 未發現頁面執行或著色器錯誤。

### 戰鬥流程與損傷

另以精簡城市幾何隔離操作流程，保留相同角色、碰撞、射擊、資源及 AI 模組：

- 新建混合配裝保留舊配置；實際輕擊與蓄力重擊、盾防禦、閃避及射擊命中。
- 暫停時任務時間不前進；恢復後繼續操作。
- 直接注入部位傷害以驗證斷臂的骨骼權重遮罩、另一側操作、三離子洩漏與重試。
- 雙腿破壞後保持低姿態、不能普通起跳，仍能使用低姿態刀劍；重試完整修復。
- 主動脫離、結果頁、重試、返回自由演習及巡邏入口。
- 波次結算 UI 使用測試傷害加速擊破，檢查三波轉換、保存紀錄及結果頁。這一項用於驗證流程；完整城市中的獵犬擊破與近戰命中另以實際攻擊驗證。

測試用的重定位／傷害入口僅由瀏覽器攔截回應注入，沒有加入發布程式；公開的 `window.__mikado.state` 維持唯讀診斷快照。

### 發射選單與介面回歸

- 真實滑鼠前進／返回側鍵不觸發瀏覽器歷史導覽；鍵盤替代鍵也能使用。
- 右鍵分割、滾輪即時選參數、不需確認、發射後保留頁面與參數；左右彈組及重新載入。
- 蚱蜢消耗 **0.3**；27 發分割仍只消耗 **1／批**；生成與調參免費。
- 正式建置產物透過 preview 開啟，檢查 **1100×760、900×650、390×844、390×650**。
- 武器、移動、三離子與部位狀態改用同一排版欄；矩形檢查確認互不重疊。收合發射選單與地圖、蚱蜢卡及左側 HUD 也不重疊。
- 正式產物的即時發射參數頁、AI 出擊與脫離正常；手機終端可捲動且無橫向溢出。

## 初版調整值與資源界限

| 項目 | 目前值 |
| --- | --- |
| 三離子 | 100；停止消耗 1.8 s 後每秒恢復 1.5，另扣傷勢洩漏 |
| 蚱蜢／射擊 | 0.3／次、1／整批 |
| 輕擊／重擊／閃避 | 0.2–0.3／次、0.5／次、0.3／次 |
| 盾 | 0.35／s，加上每次防禦受擊消耗 |
| 招架 | 起手 0.18 s；重新開啟窗口有 0.45 s 間隔 |
| 閃避 | 約 0.28 s 位移，0.62 s 間隔；沒有無敵時間 |
| 作戰區 | 基地前方半徑 270 m，高度 300 m；離區 12 s 後脫離 |
| 美特拉 | 6 m 爆炸，衰減及掩體阻隔 |
| 容量 | 16 敵人、192 敵彈、256 玩家彈、40 戰鬥特效及既有 40 命中特效上限 |

AI 在可見空中目標下擴大偵測與射擊距離；所有彈丸仍受建築與地形阻擋。場景新增腰高 1.05 m 與全高 2.1 m 掩體，沿用既有人物及日式建築比例。敵人、粒子、傷口和武器使用有界實例／物件池，重試與離開會清理活動狀態。

本環境使用軟體 WebGL；驗收用於確認邏輯、輸入、碰撞與顯示。實際更新率取決於裝置，建議開啟瀏覽器硬體加速，並利用畫質與解析度設定調整。城市與戰鬥動作均為可繼續迭代的原型，美術不是原作逐格復刻。
