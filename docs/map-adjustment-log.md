### 基地配置方向（建議，未定案）

- 依用途分成入口／公共區、訓練／排位區、會議／指揮區、技術／整備區、生活／後勤區，再用中央交通動線連通。
- 保留使用者要求的巨大基地外觀與中庭；室內門、家具、走道與樓層高度以約 1.75 公尺角色的使用尺度規劃。
- 樓層數、各區位置、地下層、入口數、完整開放的樓層範圍，等待平面圖或後續討論決定。
- 保持灰藍偏紫外殼與科技感室內；三離子設備沿用微亮青色，門牌及導引需清楚可讀。

### 每棟住宅可進入

已確認目標是每棟住宅都能進入。以下為室內內容及驗收方向的建議：

- 住宅有對應外觀的入口、窗戶、樓層與室內尺度，從街道開門後可步行進屋，也能原路離開。
- 依房型配置玄關、客廳、廚房／用餐區、臥室、浴室／洗手間；多層房屋有可通行樓梯。各房型的實際房間數待討論。
- 公寓建議包含公共入口、走廊、樓梯／電梯及各戶入口；是否每一戶、每個房間均完整開放，另行確認。
- 使用多種日式房型與家具組合，保留街景既有畫風；室內擺設不全部相同。
- 牆、地板、門、樓梯及大型家具具有一致的通行判定，第一／第三人稱鏡頭能正常使用。
- 區分「住宅全部可進入」與「所有擺設均可操作」；家具的互動種類可逐項追加，不先假定全部都有功能。
- 商場、學校、車站、倉庫、高樓等特殊建築，沿用後續框選地圖與參考圖另行規劃。

### F 鍵互動

已確認 F 用於互動；以下為建議的操作方式：

- 靠近並看向可互動物件時，顯示目標名稱與提示，例如「F 開門」「F 關門」「F 使用終端」。
- 只對目前選定、可觸及且未被牆面擋住的物件互動；一次按鍵不觸發多個物件。
- 開門後確實能走過入口，關門後恢復阻擋；門與人物、家具的相對位置要合理。
- 其他可考慮互動：電燈開關、窗戶、櫃子／抽屜、椅子／沙發、電梯按鈕、販賣機、告示牌、訓練或配裝終端。這些項目尚未逐一確認。
- 互動距離、按一下／按住、門的開啟方式、坐下與起身方式、是否記住門與物件狀態，留待細部討論。
- **既有按鍵衝突：目前 F 是切換主／副射擊側。** 後續實作需優先保留使用者指定的 F 互動，將原功能改派其他可自訂按鍵；新預設鍵尚未決定，本次未改鍵。

1. 基地樓層平面圖、房間相對位置與首批開放區域。
2. 各房間先提供可探索空間，還是同時接上訓練、任務、排名等功能。

### 全基地碰撞與可達頂樓

- 外牆、隔間、樓板、天花板、柱、樓梯、扶手、關閉的門／窗、家具及設備，需要與可見模型相符的通行阻擋。
- 檢查步行、衝刺、跳躍、閃避、蚱蜢與視角切換，不能藉高速運動或狀態切換穿過結構。
- 滑門開關與電梯移動時同步更新碰撞；電梯移動時玩家需安全跟隨轎廂，不能進入空井道。
- 城市、入口、樓層與房間銜接不能有地板縫隙、隱形牆或重疊碰撞；分區卸載不能移除玩家腳下地板。
- 頂樓要有可步行的屋面、護欄／女兒牆、屋頂設備與返回室內的出口。
- 至少一條實體樓梯可連通頂樓；電梯可另提供頂樓或前室目的地，不能用傳送替代全部樓梯。
- 屋頂配置與原作沒有呈現的空間，仍標示為 C 級設計。

### F 互動與角色狀態

- 文件建議互動範圍為視線／準星附近 **2–2.5 公尺**，選取近處、可見且具權限的物件，不能隔牆、玻璃或關閉的門觸發。
- F 執行主要動作，顯示物件名稱與動作提示；E 優先保留既有戰鬥用途，Esc 退出當前互動並正確銜接既有暫停行為。
- **座位是最高優先互動之一**：椅子、沙發、長椅、餐椅及會議椅可 F 坐下，再 F 站起。
- 坐下前檢查接近位置與占用；坐下後可轉頭、查看 UI 及使用旁邊指定設備，不能一般走動、跳躍、攻擊或衝刺。
- 站起必須找到未阻擋、同樓層的合法出口；不能穿桌、卡牆或落到樓下。離開／卸載時釋放座位占用。
- 電腦、門、電梯及販賣機列為首批互動設備；其他設備逐區擴充。
