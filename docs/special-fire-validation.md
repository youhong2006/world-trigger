# 發射選單、毒蛇／獵犬與低消耗規範

## 已確認的操作

- E 觸發目前射擊側的裝備，立方體懸浮在對應側；主、副側可各保留一組。
- 右鍵循環分割 1／8／27 發，左鍵釋放已生成的彈組；射出後需再次 E 生成。中鍵按住瞄準，舊版右鍵瞄準設定會遷移，仍可自行改綁。
- 毒蛇／獵犬右側直向方格選單：前進側鍵進入層級，返回側鍵退一層；也可用 ]／[。
- **滾輪選到的值立即生效，不需要確認。** 進入自訂數值頁後，滾輪直接改數值；三段追蹤用前進側鍵切換前／中／後列。
- 發射取用當下的參數快照；發射後保留原頁面與選項，同彈種下一次使用沿用。毒蛇／獵犬各自保存，重新載入、複製配裝及 JSON 存檔皆保留。
- 發射選單展開時滾輪不縮放鏡頭。側鍵的瀏覽器上一頁／下一頁預設行為被攔截。

## 消耗

| 操作 | 三離子消耗 |
| --- | --- |
| 蚱蜢成功放置或空中施放 | 0.3／次 |
| 射擊彈組釋放 | 1／批 |
| 生成、收起、分割、調參 | 0 |

每批分成 1、8 或 27 發均只扣 1，不依速度、威力、路線或追蹤另加費。取消及放置失敗不收費，延遲／分批不重複收費。三離子容量 100、停止施放 1.8 秒後每秒恢復 1.5 的規則保留。

## 子彈行為

毒蛇使用預設或保存的自訂四節點折線；以釋放位置和當次瞄準點為起終點，中間橫移與高度保留路線中的公尺偏移。子彈逐段飛行與碰撞，不以直線穿過彎角掩體。自訂路線若已刪除，回退直線，選單提示重選路線。

獵犬提供上方、左側、右側、發散包圍四種接近路線；包圍按同批子彈序號分散。首次釋放選定準星附近可見目標，之後依強度更新接近位置並限制轉向角速度。目標移動時能追蹤，目標消失後不自動轉鎖其他目標。沒有目標時沿路線接近準星位置，之後維持方向直到命中或射程到期。

追蹤高／中／低、以及高低低／低高低／低低高，按原先預估路程前、中、後三等分套用。自訂三段為 0–100%。速度高／中／低為 155／110／65 m/s；自訂 55–180 m/s 並獨立記住數值。發射後更改參數或路線不會改動已釋放的延遲彈組。

本文件記錄當時的發射選單版本；後續已加入美特拉爆炸、AI、近戰及部位損傷，見 [單人戰鬥驗證](battle-validation.md)。

## 驗證

`npm test` 95 項與正式建置通過，涵蓋既有城市／角色回歸，以及新增的選單層級、即時套用、獨立記憶、舊按鍵遷移、路線轉換、分段追蹤、移動目標、固定收費、轉向限制、逐段碰撞、暫停及 30／120 Hz 一致性。

Chromium／Playwright 已檢查：

- 真實滑鼠前進／返回側鍵的選單進退，不觸發瀏覽器歷史導覽；鍵盤替代鍵也可使用。
- 滾輪即時更新已生成立方體參數，沒有確認操作；選單展開時鏡頭距離不變。
- 右鍵分割、左鍵發射、每批扣 1、蚱蜢扣 0.3，生成與改參數不扣款。
- 左右立方體、第一／第三人稱、發射後保留原頁面、下次生成沿用參數。
- 毒蛇及獵犬的選項、三段模式、設定重載與手機寬度終端排版。

完整城市另外保留全部 12,408 棟建築進行測試。將原本落在基地附樓內的 T04 移到空地，第二塊掩體也移出附樓；六個靶均位於實際碰撞體外。已用毒蛇逐一實際擊破六靶，完成勝利畫面及重試，並用獵犬側面路線命中靶標；瀏覽器未發現執行錯誤。

此環境使用軟體 WebGL；測試驗證操作、碰撞與顯示，不代表所有硬體都能穩定 60 FPS。建議桌面鍵盤滑鼠及硬體加速。
