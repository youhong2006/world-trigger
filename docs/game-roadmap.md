# 遊戲規劃與實作清單

本文件依目前程式與需求討論整理。勾選代表功能已存在；未勾選代表尚未完成。需求已確認不代表程式已實作。目前已實作科技 UI、設定、三離子共用基礎、高速移動與蚱蜢；AI、子彈及刀劍戰鬥仍待後續。

## 已確認的方向

- 以單人對抗 AI 三離子兵為主，主要使用第三人稱，保留第一／第三人稱切換。
- 日本動畫風格的三門市，搭配科技感戰鬥裝備、介面、聲音與特效；城市外觀繼續依參考圖片修正。
- 自由配裝，包含蚱蜢、立方體子彈、刀劍與防禦裝備。裝備槽數、同時啟動上限及最終快捷鍵尚未定案。
- 三離子同時支撐生存與技能使用；對局內可少量恢復。受損部位、斷肢、持續洩漏、關鍵部位破壞與緊急脫離納入規劃，詳細判定待戰鬥階段確認。
- 蚱蜢：按住觸發鍵時手中顯示小光球，放開釋放；目前沒有指定蓄力增強效果。
- 地面蚱蜢放在角色前方一小段距離，原地不會踩到，往前移動後才觸發。
- 踩中或空中啟動時，有方向輸入則朝輸入方向微微向上彈射；沒有輸入則垂直向上。身體朝彈射方向傾斜。
- 空中釋放時直接在腳下生成並立即彈射；三離子足夠即可連續使用，不需落地重置次數。
- 蚱蜢一次性使用，未踩到的跳板短暫保留。確切壽命、消耗與最短施放間隔待實測調整。
- 子彈支援手動瞄準、輔助瞄準，以及依彈種使用追蹤或預設路線；先選彈道範本，再以滑鼠修改形狀，使用快捷鍵組合多組攻擊。
- 刀劍包含連擊、閃避、近身交鋒、主動格擋與招架；操作銜接及回饋參考《永劫無間》。
- 閃避是否具有無敵時間，延後至戰鬥系統階段討論，尚未定案。

- [x] 按住顯示手中光球；地面放開後生成前方跳板，不在原地誤觸。
- [x] 空中放開後在腳下立即彈射；依觸發當下的方向輸入決定方向，無輸入則垂直向上。

驗收：自動測試涵蓋方向、消耗、取消、空中接續、跳板期限、高速碰撞及不同幀率；瀏覽器檢查實際城市施放及屋頂落地。專屬蚱蜢逐格蹬踏動畫可在後續動畫精修階段繼續改善。

### 3. 第一個可玩的單人戰鬥流程

- [ ] 子彈立方體生成、分割與普通彈發射，先完成手動瞄準。
- [ ] 角色、敵人、掩體共用的命中與傷害判定，高速子彈不穿過障礙。
- [ ] 基本盾、防禦消耗、受擊回饋與三離子 HUD。
- [ ] 一種 AI 三離子兵：搜尋、追擊、攻擊、受擊與被擊破；能處理玩家在空中或屋頂的情況。
- [ ] 玩家失敗時的基本緊急脫離、重試，以及擊破敵人的勝利條件。

驗收：可以完整進行「開始挑戰 → 蚱蜢機動與射擊 → 擊破敵人或敗北 → 重試」。此時不代表完整配裝、部位損傷或所有武器已完成。
