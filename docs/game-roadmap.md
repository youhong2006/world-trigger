# 遊戲規劃與實作清單

本版已把先前未勾選的功能接成可玩的單人戰鬥初版。勾選表示功能已實作且有驗證，數值、動畫精細度與美術仍可依實際遊玩及後續參考圖調整。完整驗證範圍見 [單人戰鬥驗證](battle-validation.md)。

## 已確認規則

- 單人對抗 AI 三離子兵，以第三人稱為主，可切換第一人稱。
- 主、副側各四槽，每側同時啟動一項，可自由組合刀劍、盾、蚱蜢與四種子彈。
- 三離子同時是生存與技能資源；蚱蜢每次成功施放 0.3，射擊每批 1，生成、分割與調參免費。
- 蚱蜢按住準備、放開釋放；地面放在前方，踩到才彈射；空中釋放立即啟動。方向輸入決定水平彈射方向，沒有方向輸入則垂直向上；跳板一次性、保留 12 秒。
- 毒蛇／獵犬使用側鍵進退選單、滾輪即時選參數，射出時採用當下選項，不需確認；按彈種與配裝保存頁面和參數。
- 閃避沒有無敵時間，靠位移避開攻擊；傷勢與斷肢不會隨三離子恢復而修復。重試／重整才恢復完整戰鬥體。
- 三離子相關物件與傷口使用亮青色能量及適量光暈。

## 本版呈現範圍

城市沿用目前的三門市配置與日式建築風格；精確復刻參考畫面、逐棟特殊建築與動畫逐格精修，會隨新的圖片與區域規劃持續調整。三離子兵使用專案自製機械模型。近戰以原生 CC0 動作配合程序姿勢形成可玩的招式原型，連擊與參數可繼續依手感修改。
