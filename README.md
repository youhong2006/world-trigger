# 三門市 · Mikado City Explorer

以《境界觸發者》為靈感的非官方原創 3D 城市機動演習網頁。使用 Three.js 與 Vite，無需 API 金鑰或後端服務。

後續單人戰鬥方向、已完成／未完成清單與實作順序見 [遊戲規劃與實作清單](docs/game-roadmap.md)。目前已開放小行星射擊挑戰、自由配裝與存檔、彈道規劃、科技 UI、高速移動與蚱蜢。AI、近戰與特殊彈種行為留待後續。

## 開發

需要 Node.js 22.12+（目前使用 24）。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

正式建置：`npm run build`。預覽建置：`npm run preview -- --port 4173`。

## 目前可玩的內容

首頁點「射擊挑戰」，90 秒內擊破六個固定練習靶，完成「開始 → 射擊與蚱蜢機動 → 勝利或時間／三離子耗盡 → 成績 → 重試」。本次沒有 AI、三離子兵或敵人攻擊。「自由演習」保留城市探索。

小行星彈可生成亮青色立方體，分割 1／8／27 發，調整每發威力、彈速、射程、散射、延遲和齊射／分批。彈丸採連續線段碰撞，由角色側方發射，準星與槍口均考慮掩體。毒蛇與美特拉可選用及發射，**目前共用普通直射規則**，尚未加入毒蛇轉折或美特拉爆炸。

## 操作

| 操作 | 預設按鍵 |
| --- | --- |
| 移動／衝刺／跳躍 | WASD（或方向鍵）／Shift／Space |
| 準備、釋放蚱蜢 | 按住 Q 準備，放開釋放 |
| 生成／收起立方體 | E |
| 發射／瞄準 | 滑鼠左鍵（按住連發）／右鍵（按住） |
| 切換主槽／副槽 | 1–4／5–8 |
| 切換射擊側／輔助目標 | F／T |
| 蹲下／站立 | C |
| 第一／第三人稱 | V；滾輪調整第三人稱距離 |
| 返回起點並重整三離子 | R |
| 暫停選單／設定 | Esc／F2 |
| 釋放游標 | Tab；點擊場景繼續環顧 |

地面放置的蚱蜢在前方 1.7 公尺，走上去才會觸發；空中釋放則立即在腳下彈射。啟動時有方向輸入就朝該方向微微向上，無方向輸入則垂直向上。三離子足夠即可連續空中施放。每次生成消耗 4／100 三離子，跳板保留 12 秒且只使用一次；停止施放 1.8 秒後每秒恢復 1.5。這些是目前的演習調整值。

預設一般移動 5 m/s、衝刺 14 m/s、蚱蜢水平速度 42 m/s，均可在設定調整。高速碰撞分段檢查，支援平屋頂及切妻／寄棟屋頂的表面落地。可在空中跨河，低處涉水會返回安全起點。

設定包含主音量、環境音與技能音效、音效試聽、靈敏度、垂直反轉、按住／切換操作、移動速度、視野、肩部視角、跟隨距離、畫質與解析度、陰影、更新上限、HUD、準星、光暈及減少動態效果。支援按鍵改綁（衝突時交換）、本機保存、重設及 JSON 匯入／匯出。Esc、Tab、F2 保留。開啟選單或切換視窗會暫停並取消未釋放的技能。

自由配裝提供主副側各四槽、各啟動一項，最多六套配置。小行星、毒蛇及美特拉的參數分別保存；Q 使用目前啟動的蚱蜢，與另一側射擊可同時操作。生成立方體時支付三離子；收起或切換裝備不退還消耗。預設八發彈組消耗 9。

彈道規劃器提供範本、俯視拖曳節點、高度調整、立體預覽、路線模擬與最多八組命名路線，可連結到配裝。**小行星維持直射**，路線目前只保存給未來的特殊彈種。

設定、完整配裝、彈道路線與最佳成績保存在目前瀏覽器，並可由設定 → 其他匯出／匯入完整 JSON 存檔。進行中的挑戰與角色位置不保存，沒有帳號或雲端同步。

完整操作見 [角色操作說明](docs/player-controls.md)，驗證範圍見 [機動演習驗證](docs/mobility-validation.md) 與 [射擊演習驗證](docs/shooting-validation.md)。角色使用 VRoid Studio 的 CC0 男性動漫模型 HairSample_Male，身高約 1.75 公尺；八組 Quaternius CC0 動作搭配手臂準備姿勢及彈射傾斜。來源與授權見 [模型授權紀錄](public/models/avatar/ATTRIBUTION.md)。

需要支援 WebGL 的瀏覽器與硬體加速；步行操作以桌面鍵盤與滑鼠為主。介面使用系統字型，不依賴外部字型服務。場景並非原作城市的精確復刻。

## GitHub Pages

部署網址：`https://youhong2006.github.io/world-trigger/`。

推送至 `main` 會啟動 `.github/workflows/pages.yml`，安裝、建置並部署網站。
儲存庫 Settings → Pages → Build and deployment 的 Source 應為 **GitHub Actions**。
若首次自動啟用 Pages 權限不足，請先在該處選擇 GitHub Actions，再到 Actions 重新執行部署工作流程。
Vite 的 `base` 已設定為 `/world-trigger/`，以正確載入專案網站的資源。

## 大範圍城市配置

城市主要聚落已擴展為約 7 × 6 公里的不規則盆地，以中央 BORDER、向外移動的彎曲河道、三座橋梁、密集住宅區及四周山群為骨架。住宅會逐漸過渡為農地、林地與山坡，整體地形使用一張連續網格，沒有方形城市底板。進入頁面會顯示城市總覽，可拖曳旋轉、滾輪縮放；右上「城市總覽」可隨時返回鳥瞰。建築與樹木使用實例化渲染以減少繪圖呼叫。

[城市配置與推定範圍](docs/city-plan.md) 記錄參考圖的配置、座標與配色，供後續圖片持續校正。

配置與碰撞測試：`node --test src/city-layout.test.js`。

住宅採用日式動畫風格：分層滑窗、瓦屋頂、米白／灰藍／淡綠外牆，以及近景門廊、陽台、雨槽與冷氣外機。房屋長寬在前次放大 35% 後再增加 1.25 倍，人物視線為 1.63 公尺，門高 2.1 公尺，每層樓高 3.3 公尺。「住宅街」提供近距離屋頂預覽與步行入口。

住宅街採連續沿街地塊與背靠背住宅列，核心區填滿可建用地，外緣逐步淡出。住宅巷寬 5 公尺、支路 6 公尺、幹道 12 公尺，兩側有白色邊線；宅前以 3.8 公尺鋪面、低圍牆、植栽、車格與小型車取代大片草坪。房屋及停車設施都有碰撞避讓。

建築比例、街廓密度與碰撞測試：`node --test src/*.test.js`。


移動、鏡頭、街廓與碰撞回歸測試：`npm test`。GitHub Pages 發布前也會執行這些檢查。
