# 三門市 · Mikado City Explorer

以《境界觸發者》為靈感的非官方原創 3D 城市與單人戰鬥網頁。使用 Three.js 與 Vite，無需 API 金鑰或後端服務。

後續單人戰鬥方向、已完成／未完成清單與實作順序見 [遊戲規劃與實作清單](docs/game-roadmap.md)。目前已開放四類 AI、三種任務與難度、刀劍連擊／防禦／招架／閃避、部位損傷與緊急脫離、四種子彈、自由配裝存檔、彈道規劃、科技 UI、高速移動及蚱蜢。完成清單與數值見上述文件。

首頁「探索 BORDER 基地」開放四側連通的室內：主屋頂 350 m、建築區深 160 m、一般層高 6 m，含 B2／B1、1F–58F 與 RF。由平地正面大門進入，可使用 F 操作門、設備與座椅，透過平面導覽、電梯及連續樓梯探索各區。2F／3F 有排名大廳，7F 有實體射擊靶場，獨立虛擬六靶訓練也保留。房間採 18 類模組家具與附近分區載入；樓層及尺寸屬遊戲設計。完整範圍、來源分級及未完成項目見 [基地實作紀錄](docs/border-headquarters/implementation.md)。外圍住宅室內尚未製作。

## 開發

需要 Node.js 22.12+（目前使用 24）。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

正式建置：`npm run build`。預覽建置：`npm run preview -- --port 4173`。

## 目前可玩的內容

首頁點「單人作戰」，選擇防衛波次、巡邏清剿或核心討伐及難度。可建立一套新的「近戰混合」配裝，主側 1 刀劍、2 小行星、3 毒蛇、4 美特拉；副側 5 盾、6 蚱蜢、7 獵犬。以目前配置出擊，完成戰鬥、結算、重試或返回自由演習。

首頁點「射擊挑戰」，90 秒內擊破六個固定練習靶，完成「開始 → 射擊與蚱蜢機動 → 勝利或時間／三離子耗盡 → 成績 → 重試」。固定靶演習獨立於 AI 任務。「自由演習」保留城市探索。

小行星彈可生成亮青色立方體，分割 1／8／27 發，調整每發威力、彈速、射程、散射、延遲和齊射／分批。彈丸採連續線段碰撞，由角色側方發射，準星與槍口均考慮掩體。毒蛇可沿預設或自訂折線飛行；獵犬提供上方、左／右側及發散包圍路線與分段追蹤。美特拉撞擊後產生 6 m 爆炸，傷害依距離衰減，掩體可擋住爆風。

## 操作

斷臂會停用對應側觸發器，斷腿降低移動與跳躍；傷勢持續洩漏三離子，少量恢復不修復身體。頭部／核心破壞或能量耗盡時緊急脫離，重試重整身體。敵人發光核心是弱點，橘色提示是攻擊前兆；裝甲型可用蓄力重擊突破。

| 操作 | 預設按鍵 |
| --- | --- |
| 移動／衝刺／跳躍 | WASD（或方向鍵）／Shift／Space |
| 準備、釋放蚱蜢 | 按住 Q 準備，放開釋放 |
| 生成／收起立方體 | E |
| 分割子彈／發射 | 右鍵循環 1→8→27→1／左鍵釋放當前彈組 |
| 刀劍輕擊／重擊 | 刀劍啟動時左鍵連擊／G 按住蓄力、放開斬擊；空中使用空斬 |
| 防禦／招架 | 按住 X；持刀時也可按住右鍵，起手 0.18 s 可招架正面攻擊 |
| 方向閃避 | Alt + 方向，無方向時後撤，沒有無敵時間 |
| 緊急脫離 | B |
| 瞄準 | 按住滑鼠中鍵 |
| 發射選單進入／返回 | 前進側鍵／返回側鍵（也可用 ]／[） |
| 發射選單選參數 | 滾輪選中即生效，不需確認 |
| 切換主槽／副槽 | 1–4／5–8 |
| 切換射擊側／輔助目標 | Z／T |
| 基地設備、門、座椅 | F 互動；再按 F 站起 |
| 蹲下／站立 | C |
| 第一／第三人稱 | V；滾輪調整第三人稱距離 |
| 返回起點並重整三離子 | R |
| 暫停選單／設定 | Esc／F2 |
| 釋放游標 | Tab；點擊場景繼續環顧 |

地面放置的蚱蜢在前方 1.7 公尺，走上去才會觸發；空中釋放則立即在腳下彈射。啟動時有方向輸入就朝該方向微微向上，無方向輸入則垂直向上。三離子足夠即可連續空中施放。每次成功施放消耗 0.3／100 三離子，跳板保留 12 秒且只使用一次；停止施放 1.8 秒後每秒恢復 1.5。這些是目前的演習調整值。

預設一般移動 5 m/s、衝刺 14 m/s、蚱蜢水平速度 42 m/s，均可在設定調整。高速碰撞分段檢查，支援平屋頂及切妻／寄棟屋頂的表面落地。可在空中跨河，低處涉水會返回安全起點。

設定包含主音量、環境音與技能音效、音效試聽、靈敏度、垂直反轉、按住／切換操作、移動速度、視野、肩部視角、跟隨距離、畫質與解析度、陰影、更新上限、HUD、準星、光暈、鏡頭震動、受擊光暈及減少動態效果。支援按鍵改綁（衝突時交換）、本機保存、重設及 JSON 匯入／匯出。Esc、Tab、F2 保留。開啟選單或切換視窗會暫停並取消未釋放的技能。

自由配裝提供主副側各四槽、各啟動一項，最多六套配置。小行星、毒蛇、獵犬及美特拉的參數分別保存；Q 使用目前啟動的蚱蜢，與另一側射擊可同時操作。E 生成的立方體懸浮於對應側，右鍵分割，左鍵釋放；**每批發射固定消耗 1 點**，不隨分割數、威力、速度或追蹤變化。生成、分割、調參與收起免費。

彈道規劃器提供範本、俯視拖曳節點、高度調整、立體預覽、路線模擬與最多八組命名路線，可連結到配裝。毒蛇可選用自訂路線，依當次發射位置與瞄準點映射折線；**小行星維持直射**。

毒蛇／獵犬使用畫面右邊直向方格選單，側鍵進入或退出層級，滾輪選到的值立即生效。發射時固定當下參數；發射後保留頁面位置，下一次使用同彈種沿用設定。自訂數值以滾輪直接調整，獵犬三段數值用前進側鍵切換調整列。展開此選單時，滾輪不縮放鏡頭。

設定、完整配裝、彈道路線、射擊與各任務難度最佳成績保存在目前瀏覽器，並可由設定 → 其他匯出／匯入完整 JSON 存檔。進行中的挑戰與角色位置不保存，沒有帳號或雲端同步。

完整操作見 [角色操作說明](docs/player-controls.md)，驗證範圍見 [機動演習驗證](docs/mobility-validation.md) 、[初版射擊驗證](docs/shooting-validation.md) 、[發射選單與特殊子彈驗證](docs/special-fire-validation.md) 與 [單人戰鬥驗證](docs/battle-validation.md)。角色使用 VRoid Studio 的 CC0 男性動漫模型 HairSample_Male，身高約 1.75 公尺；14 組 Quaternius CC0 移動與戰鬥動作，搭配手臂準備、持刀側鏡像與彈射傾斜。來源與授權見 [模型授權紀錄](public/models/avatar/ATTRIBUTION.md)。

需要支援 WebGL 的瀏覽器與硬體加速；步行操作以桌面鍵盤與滑鼠為主。介面使用系統字型，不依賴外部字型服務。場景並非原作城市的精確復刻。

## GitHub Pages

部署網址：`https://youhong2006.github.io/world-trigger/`。

推送至 `main` 會啟動 `.github/workflows/pages.yml`，安裝、建置並部署網站。
儲存庫 Settings → Pages → Build and deployment 的 Source 應為 **GitHub Actions**。
若首次自動啟用 Pages 權限不足，請先在該處選擇 GitHub Actions，再到 Actions 重新執行部署工作流程。
Vite 的 `base` 已設定為 `/world-trigger/`，以正確載入專案網站的資源。

## 大範圍城市配置

城市主要聚落已擴展為約 7 × 6 公里的不規則盆地，以中央 BORDER、向外移動的彎曲河道、三座橋梁、密集住宅區及四周山群為骨架。住宅會逐漸過渡為農地、林地與山坡，整體地形使用一張連續網格，沒有方形城市底板。進入頁面會顯示城市總覽，可拖曳旋轉、滾輪縮放；右上「城市總覽」可隨時返回鳥瞰。建築與樹木使用實例化渲染以減少繪圖呼叫。

[城市配置與推定範圍](docs/city-plan.md) 記錄參考圖的配置、座標與配色，供後續圖片持續校正。

配置與碰撞測試：`node --test src/city-layout.test.js`。

住宅採用日式動畫風格：分層滑窗、瓦屋頂、米白／灰藍／淡綠外牆，以及近景門廊、陽台、雨槽與冷氣外機。房屋長寬在前次放大 35% 後再增加 1.25 倍，人物視線為 1.63 公尺，門高 2.1 公尺，每層樓高 3.3 公尺。「住宅街」提供近距離屋頂預覽與步行入口。

住宅街採連續沿街地塊與背靠背住宅列，核心區填滿可建用地，外緣逐步淡出。住宅巷寬 5 公尺、支路 6 公尺、幹道 12 公尺，兩側有白色邊線；宅前以 3.8 公尺鋪面、低圍牆、植栽、車格與小型車取代大片草坪。房屋及停車設施都有碰撞避讓。

建築比例、街廓密度與碰撞測試：`node --test src/*.test.js`。


移動、鏡頭、街廓與碰撞回歸測試：`npm test`。GitHub Pages 發布前也會執行這些檢查。
